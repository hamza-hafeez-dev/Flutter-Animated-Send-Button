# Flutter Animated Send Button

A simple Flutter animation project built using `AnimationController`.

When the **Send** button is pressed, the send icon smoothly slides to the right and a green success container appears with a **Done** icon.

## Preview

!Preview/Flutter Demo - Google Chrome 2026-09-25 01-06-50.mp4

## Features

- Smooth Send button animation
- Send icon slides to the right
- Green success state
- Done icon animation
- Built with `AnimationController`
- Clean and simple UI

## Technologies

- Flutter
- Dart
- AnimationController
- Tween Animation

## What I Learned

This project helped me understand how to use `AnimationController` to control animations and create smooth UI state changes in Flutter.
